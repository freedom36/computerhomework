# 化学实验学习平台 · 含 MSDS / 计算工具 / 仪器台账（交付包）

在 `index(2).html`（26 个实验的完整平台）基础上，**只新增**了三个模块：
「化学品 MSDS 查询」「计算工具」「仪器台账」；
实验数据、详情页、管理后台、资料上传抽取等原有功能与界面均未改动。

## 一、四个模块

搜索框上方是模块切换，共四个：

| 模块 | 说明 |
| --- | --- |
| 实验查询 | 原平台的实验搜索（默认模式，行为与原来完全一致） |
| 化学品 MSDS | 12 种常见化学品的教学摘要，按名称 / 化学式 / CAS / 危险性关键词检索 |
| 计算工具 | 物质的量换算 n=m/M、产率 = 实际产量 / 理论产量 × 100% |
| 仪器台账 | 仪器名称 / 规格 / 数量 / 状态的登记与删除，数据存本机浏览器 |

### 化学品 MSDS

| 输入示例 | 结果 |
| --- | --- |
| `硫酸`、`H2SO4`、`H₂SO₄`、`7664-93-9` | 浓硫酸详情 |
| `酒精` | 乙醇（酒精） |
| `水银` | 汞（水银） |
| `腐蚀`、`易燃`、`致癌` | 命中的多种化学品列表 |

化学式支持普通数字与下标混输（`H2SO4` 等价 `H₂SO₄`）。详情含：危害标签、化学式 / CAS、健康危害、防护措施、急救处理、储存要求，以及「返回化学品列表」。

### 计算工具

- **物质的量换算**：填质量 m（g）与摩尔质量 M（g/mol），得 n（mol，保留 4 位小数）。
- **产率计算**：填实际产量与理论产量（单位一致即可），得百分比（保留 1 位小数）。
- 两处都有输入校验：空值、M≤0、理论产量≤0、负数会给出提示，不会算出无意义结果。

### 仪器台账

- 登记：仪器名称（必填）、规格、数量（≥1 的整数）、状态（完好 / 在用 / 损坏）。
- 清单：表格列出全部条目，状态用彩色标签区分，可逐条删除。
- 存储：`localStorage` 键 `chem_instruments`，刷新不丢失；首次打开有 4 条示例（烧杯、量筒、容量瓶、玻璃棒）。
- 换设备 / 换浏览器不共享；清站点数据会重置为示例数据。

## 二、代码改动范围（便于核对）

相对 `index(2).html`，全文只有以下变化，原有内容一行未删未改：

1. `<style>` 末尾追加 MSDS、计算工具、仪器台账的样式（原有样式未动）。
2. 搜索区 `.wrap` 内插入 4 个模块切换按钮。
3. `<main>` 内追加两个面板容器 `#calcPanel`、`#ledgerPanel`（默认 `hidden`）。
4. 搜索事件绑定由 `search(elQ.value)` 改为 `runSearch()`，按模式分流（3 行）。
5. `</script>` 前追加模块代码：MSDS 数据与检索、计算工具、仪器台账、`setSearchMode`。

未改动：26 个实验数据、详情渲染、管理后台、上传抽取、页头页脚、配色与布局。

## 三、运行方式

- **直接双击** `index.html` 即可离线使用。
- 或本地起服务（与线上一致）：`node server.js`，访问 `http://localhost:3000`。
- 纯静态托管时只需上传 `index.html`，入口文件名保持 `index.html`。

## 四、说明

- MSDS 内容为**教学摘要**，非官方 SDS，实际操作以药品官方安全技术说明书与实验室规程为准。
- 三个新模块与实验数据互不干扰：实验存 `chem_exps_v1`，台账存 `chem_instruments`，MSDS 与计算工具不写存储。
- 管理后台的「导入 / 导出 JSON」只作用于实验数据，不会覆盖台账。
